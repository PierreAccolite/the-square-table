CamLapse portable FFmpeg
=========================

Place the Windows FFmpeg executable here:

    tools\\ffmpeg\\ffmpeg.exe

CamLapse does not require FFmpeg for live preview, photos, or basic OpenCV video recording. FFmpeg is used to convert captured timelapse frames into MP4.

Use a trusted FFmpeg Windows build and copy only ffmpeg.exe into this directory.

Official FFmpeg project: https://ffmpeg.org/download.html

Do not rename the executable. CamLapse expects:

    tools\\ffmpeg\\ffmpeg.exe
